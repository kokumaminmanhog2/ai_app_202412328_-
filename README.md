## 노트북 실행 방법 (Google Colab)

설치할 것은 없습니다. 브라우저만 있으면 됩니다.

1. 위 표에서 `.ipynb` 파일을 클릭합니다.
2. 화면 상단의 **Download raw file** 버튼으로 파일을 내려받습니다.
3. [Google Colab](https://colab.research.google.com) 에 접속 → **업로드** 탭 → 내려받은 파일 선택
4. 셀을 위에서부터 순서대로 실행합니다 (`Shift + Enter`)

> 💡 Colab에서 작업한 내용은 **내 드라이브에 사본 저장**을 해두어야 남습니다.

### 파일을 한 번에 받고 싶다면

초록색 **Code** 버튼 → **Download ZIP** 을 누르면 전체를 한 번에 받을 수 있습니다.

## 과제 제출 방법

1. 모든 셀을 실행해 채점 셀에 **"문제 N 통과!"** 가 출력되는지 확인합니다.
2. Colab에서 `파일 → 다운로드 → .ipynb 다운로드`
3. 파일명을 `과제N_과목명_학번_이름.ipynb` 형식으로 변경합니다.
4. 담당 교수 이메일로 제출합니다. **메일 제목: `[AI응용] 과제N_학번_이름`**

- 마감: 다음 주 수업 전날 23:59
- 채점 셀(`assert`)을 수정하면 해당 문제는 0점 처리됩니다.

## 질문하는 방법

질문은 **카카오톡 오픈채팅방**으로 받습니다. 공통 질문은 다음 수업 첫 10분에 함께 설명합니다.

질문할 때는 아래 3가지를 함께 올려주세요. 훨씬 빨리 해결됩니다.

1. 어떤 셀에서 발생했는지 (문제 번호)
2. **에러 메시지 전체 캡처** (마지막 줄만 말고 전체)
3. 무엇을 시도해봤는지

같은 조 상급생(피어 튜터)에게 먼저 물어보는 것도 좋은 방법입니다.
